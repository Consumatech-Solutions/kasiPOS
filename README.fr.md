# KasiPOS Frontend

**KasiPOS** est une application web conçue pour gérer les opérations quotidiennes de manière rapide, fluide et fiable, avec un fonctionnement offline-first adapté aux environnements de vente où la connexion Internet peut être instable.

## Contenu de ce repo

- Modules de point de vente (POS) et de gestion des opérations, développés avec Next.js App Router
- Architecture local-first, pensée pour les connexions limitées ou intermittentes
- Outils de qualité et de tests pour garantir des flux fiables en production

## Démarrage rapide

### Prérequis

- Node.js 20.x LTS
- npm

### Installation

```bash
git clone <your-fork-or-repo-url>
cd kasiPOS
npm install
```

### Lancement

```bash
npm run dev
```

### Verification

```bash
npm run lint
npm run typecheck
npm run test
```
